# 용인시 실시간 빗물 지도

기상청 레이더(5분 간격)와 환경부 토지피복지도를 합쳐서, 용인시 기흥구·수지구·처인구에 **지금 비가 얼마나 오는지**, **그 비가 땅에 따라 얼마나 흘러나가는지**를 보여주는 웹 지도입니다.

```
기상청 레이더 (5분마다)  ×  토지피복별 CN (환경부 토지피복도)  =  실시간 직접유출
      "얼마나 오나"               "얼마나 스며드나"                  "얼마나 흘러가나"
```

## 화면 구성 (일반 시민 눈높이)

- **보기 전환 [비 | 땅 | 흘러간 빗물]**
  - 비: 레이더로 본 비의 세기(시간당 mm). 레이더가 500 m 칸 단위라 네모나게 보임(일부러 다듬지 않음)
  - 땅: 도시·논밭·숲·풀밭·습지·맨땅·강호수. 범례를 누르면 그 땅만 진하게 보이고 구별 비율이 표시됨
  - 흘러간 빗물: 장면마다 그 시각까지 최근 3시간 동안 땅에 스며들지 않고 흘러간 빗물(mm)
- **재생 막대:** 최근 1시간 13장면을 반복 재생(실제 관측만, 예측 없음)
- **구별 카드:** 지금 비의 세기, 최근 3시간 내린 비, 흘러간 빗물, 흘러간 비율, '땅 구성'과 '빗물이 나온 곳' 비교 막대
- **비가 똑같이 와도, 땅마다 달라요:** 비의 양을 움직여 땅 종류별 흘러간 빗물 비교
- **설명 칸:** 계산 방법, 빗물 흘림 점수(CN), 용어 풀이를 쉬운 말로 정리(자세한 내용은 펼쳐 보기)
- 지도 위 동그라미는 **지상 관측소**(기상청 자동 관측 장비, AWS)에서 실제로 잰 비

## 계산 방법

| 항목 | 내용 |
|---|---|
| 강수 | 기상청 레이더 합성자료(HSR, 500 m, 5분). 반사도 → 강수강도는 Z = 200R^1.6 |
| 누적 강수 P | 장면마다 직전 3시간(36장면)의 강수를 합산. 빠진 장면은 앞 장면 값으로 최대 15분까지 보완 |
| 유출 방법 | SCS-CN(NRCS-CN): Q = (P − 0.2S)² / (P + 0.8S), S = 25400/CN − 254 |
| CN 값 | 국토교통부 「홍수량 산정 표준지침」(2019) 표 3.1 국내 유출곡선지수 기준(AMC-II). 논은 지침대로 AMC별 70/79/89 |
| 토양군 | 토양도가 없어 **용인 전역을 한 토양군(기본 B)으로 가정**. 환경변수 `SOIL_GROUP`으로 바꿈 |
| AMC | 사건 이전 5일 강수(레이더 용인 평균)로 I/II/III을 정함. 기록이 5일치 쌓이기 전에는 AMC-II |
| 토지피복 | 환경부 세분류 토지피복지도(2025 사업분)를 중분류(L2)로 약 25 m 격자화 |

`pipeline/runoff.py` 맨 위에 CN 표가 있습니다. 2025년 분류 중 지침과 이름이 다른 4종(인공초지, 자연나지, 인공나지, 시설재배지)은 가장 가까운 항목을 썼고, 대응 관계를 주석으로 적어 두었습니다.

## 폴더 구성

| `pipeline/runoff.py` | CN 표, SCS-CN 공식, AMC 판정 |

| `web/data/landcover.png`, `landcover.json`, `districts.geojson` | 토지피복 그림, 면적 통계, 구 경계 (토지피복도에서 만듦) |
| `state/` | 실행 사이에 이어지는 자료: 최근 4시간 레이더, 선행강우 기록 (자동 생성) |

## 1. 기상청 API허브 활용신청

[apihub.kma.go.kr](https://apihub.kma.go.kr)에 가입하고 아래 세 가지를 **활용신청**하세요.

1. 레이더 → 레이더합성자료 다운로드 (`typ04/url/rdr_cmp_file.php`)
2. 지상관측 → AWS 매분자료 (`typ01/cgi-bin/url/nph-aws2_min`)
3. 지상관측 → 지점정보 (`typ01/url/stn_inf.php`)

3번이 안 되면 `pipeline/stations.csv`(열: `stn,name,lon,lat`)를 직접 만들어 넣으세요.

## 2. 내 컴퓨터에서 실행 (Windows 명령 프롬프트)

```
cd 압축푼경로\yongin-rain
pip install -r pipeline\requirements.txt

rem 키 없이 시험 (가짜 비구름 + 실제 토지피복)
python pipeline\fetch.py --demo

rem 실제 자료
set KMA_API_KEY=발급받은키
python pipeline\fetch.py
python pipeline\fetch.py --time 202307150300   (비 오던 과거 시각으로 시험)

rem 웹 지도 보기 → 브라우저에서 http://localhost:8000
python -m http.server 8000 -d web
```

- 처음 실행할 때는 레이더 48장면(4시간치)을 받느라 몇 분 걸립니다. 다음부터는 새 장면만 받습니다.
- `--gis`를 붙이면 `web/data/`에 QGIS용 격자 파일도 생깁니다: `rain.asc`(지금 강수강도), `rain3h.asc`(3시간 누적 강수), `runoff.asc`(3시간 유출고, 25 m). 좌표계는 EPSG:4326입니다.
- 인증키는 `set`으로만 넣고 파일에 쓰지 마세요.

## 3. 웹에 올려서 자동 갱신 (GitHub, 무료)

1. GitHub에 새 저장소를 만들고 이 폴더 전체를 올리세요(`.github` 폴더 포함).
2. Settings → Secrets and variables → Actions → **New repository secret**: 이름 `KMA_API_KEY`, 값은 인증키
3. (선택) 같은 화면의 **Variables** 탭에서 `SOIL_GROUP`을 A~D 중 하나로 지정
4. Settings → Pages → Source를 **GitHub Actions**로 바꾸세요.
5. Actions 탭 → "강수·유출 지도 갱신" → **Run workflow**를 누르세요.
6. `https://아이디.github.io/저장소이름/`에서 지도가 열립니다. 이후 10분마다 자동 갱신됩니다.

실행할 때마다 결과를 저장소에 커밋하지 않고, 최근 레이더와 선행강우 기록만 GitHub 캐시(`state/`)로 다음 실행에 넘깁니다. 캐시가 지워지면 처음처럼 4시간치를 다시 받고, AMC는 5일치가 다시 쌓일 때까지 II로 계산합니다.

## 토지피복도를 바꿀 때

새 토지피복도(EPSG:4326 GeoJSON, `L2_CODE`와 `ADM_CD` 열 필요)로 다시 만들려면:

```
pip install matplotlib
python pipeline\prepare_landcover.py landcover.geojson
```

구는 `ADM_CD` 앞 5자리(31191 처인구, 31192 기흥구, 31193 수지구)로 나눕니다. 구 경계(`districts.geojson`)도 이 격자에서 자동으로 만들어집니다.

## 한계

- **레이더 강수는 추정값**이라 지상 실측과 차이가 날 수 있습니다. 그래서 AWS 실측을 같이 표시합니다.
- **토양군을 하나로 가정**했습니다. 흙토람 정밀토양도를 반영하면 더 정확해집니다.
- CN 표는 미국 기준을 바탕으로 해서 우리나라 산림·논에 그대로 맞지 않는다는 지적이 있습니다.
- 3시간 이동 누적은 실제 호우 사건의 시작·끝과 다를 수 있습니다. 하천으로 흘러가는 시간(도달시간)과 하수도는 고려하지 않은 **"그 자리에서 생기는 직접유출"**입니다.
- 하천·저수지·습지는 기준상 CN 100이라 내린 비가 모두 유출로 계산됩니다.
